# Formati per lo scambio dei dati

Corso sui principali formati utilizzati per lo scambio di dati tra applicazioni e sistemi.

## Indice del Corso

### 1. JSON (JavaScript Object Notation)
- Introduzione a JSON
- Sintassi e struttura
- Tipi di dati
- Oggetti e array
- Validazione e schema JSON
- Utilizzo pratico e casi d'uso
- Strumenti e librerie

### 2. XML (eXtensible Markup Language)
- Introduzione a XML
- Sintassi e struttura
- Elementi e attributi
- DTD (Document Type Definition)
- XML Schema (XSD)
- XSLT e trasformazioni
- Namespace XML
- Utilizzo pratico e casi d'uso
- Strumenti e librerie

### 3. Altri Formati
- CSV (Comma-Separated Values)
- YAML (YAML Ain't Markup Language)
- TOML (Tom's Obvious, Minimal Language)
- Protocol Buffers
- MessagePack
- Confronto tra i vari formati
- Criteri di scelta del formato appropriato

## Obiettivi del Corso

- Comprendere le caratteristiche principali dei formati di scambio dati
- Saper scegliere il formato più adatto per diverse esigenze
- Acquisire competenze pratiche nell'utilizzo di JSON e XML
- Conoscere formati alternativi e i loro ambiti di applicazione

## Prerequisiti

- Conoscenze base di programmazione
- Familiarità con concetti di strutture dati

## Risorse

Materiali e esempi pratici saranno forniti durante il corso.
